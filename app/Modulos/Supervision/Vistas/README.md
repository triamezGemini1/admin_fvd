# Vistas — módulo Supervisión

La UI de supervisión FVD está en **`panel.html`** (pestañas *Supervisión FVD*) y se renderiza en **`src/js/panel.js`** (`loadSupervisionPanel`).

`panel.html` en esta carpeta es copia de referencia para el registro de rutas.

Tablas: `admin-crud-table--compact`, `text-sm`, `admin-cell-truncate` y scroll horizontal (`admin-fin-pane`, `ag-inf-scroll`).
