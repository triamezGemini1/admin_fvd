# Vistas — módulo Delegados

La interfaz del delegado vive en **`panel.html`** (raíz) y se renderiza dinámicamente en **`src/js/panel.js`** (`mountDelegadoPanel`, afiliaciones, carnet, traspasos).

`panel.html` en esta carpeta es una copia de referencia para el registro de rutas del módulo.

Tablas delegado: clases `admin-crud-table--compact`, `text-sm` y contenedor con scroll `admin-fin-pane`.
